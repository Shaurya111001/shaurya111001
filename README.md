## ⚡ What I'm building

### `Parallel Monte Carlo Risk Engine`

A C++ / OpenMPI project for distributed portfolio-risk simulation.

**Current focus**

- Parallel Monte Carlo simulation across MPI processes
- Portfolio risk estimation
- Value at Risk `(VaR)`
- Expected Shortfall `(CVaR)`
- Execution-time benchmarking
- Speedup and parallel-efficiency analysis

**Stack**

`C++17` `OpenMPI` `CMake` `Linux` `Monte Carlo` `Quantitative Finance`

> The goal is not simply to calculate a number — it is to understand how numerical workloads behave when pushed across multiple processes.
